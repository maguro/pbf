## Code review

Before you report a defect that existed before the change, search the open
issues. If an issue covers the defect, give the issue number. Do not describe
the defect again.

Report only problems. Do not list the checks that pass. If earlier reviews of
the same pull request found problems, state which of those problems the
author fixed after the previous review.

The steps in "Before each commit" in `AGENTS.md` are for the author of a
change. Do not do them in a review, and do not report them.
